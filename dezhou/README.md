# 德州扑克 · 单机对战（静态网页）

纯 HTML / CSS / JS，**零依赖、无需构建、不用联网**。双击 `index.html` 就能在浏览器里和机器人打 Unlimited Hold'em。

## 玩法

1. 打开 `index.html`。
2. 在「新牌局」里选：
   - **机器人数量**：1 ~ 8 个对手（总座位 2 ~ 9 人桌）。
   - **机器人水平**：新手 / 休闲 / 中级 / 高手 / 职业。点一个水平会应用到全部机器人，也可以在下方列表里**逐个调整**每个机器人的水平与性格。
   - **盲注**：小盲 / 大盲可自定义。
   - **初始筹码**：1000 / 2000 / 5000 / 10000。
   - **机器人思考速度**：慢 / 正常 / 快 / 极快。
3. 点「开始对局」。轮到你时，底部行动条会出现 弃牌 / 过牌 / 跟注 / 加注 / 全下。

### 数据口径

顶栏显示：手数、盲注、我的筹码、实时胜率（对随机手牌）、净收益。右上角「战绩」里有赢手率、每手平均收益、对手水平一览；「补码」可以给自己补筹码。

## 机器人水平

| 水平 | 起手牌门槛 | 胜率估算 | 底池赔率 | 位置意识 | 诈唬 |
| --- | --- | --- | --- | --- | --- |
| 新手 | 很松，爱跟注 | 粗略牌力打分 | 几乎不看 | 无 | 极少 |
| 休闲 | 偏松 | 少量蒙特卡洛采样 | 粗看 | 一点点 | 偶尔 |
| 中级 | 正常 | 蒙特卡洛 ~320 次 | 按赔率跟注 | 有 | 一般 |
| 高手 | 收紧 | ~520 次 | 严格 | 明显 | 较多 |
| 职业 | 按位置收紧 | ~760 次 | 严格 + 隐含赔率 | 很强 | 价值/诈唬平衡 |

性格（紧手 / 均衡 / 激进）会在此基础上调整起手门槛和攻击性。`node tests/ai-test.js` 里有客观对照：职业对新手 1000 手净赢约 6 万筹码，职业对休闲约 10 万。

## 规则实现

- 无限注德州扑克：翻牌前 → 翻牌 → 转牌 → 河牌，每街一轮下注，河牌后摊牌。
- 单挑：庄家下小盲、翻牌前先行动，翻牌后**后**行动；3 人以上从大盲下家开始。
- 加注规则：完整加注会重新打开行动权；筹码不够时全下但不改变最小加注额。
- **未跟注退回**：一方下注超过对手能跟的额度时，多余部分在结算时退回（不会提前退回，对手始终有机会跟注全下）。
- **边池**：按每人本手投入分层，主池 / 边池分别比牌，多个边池会自动合并显示；平局按庄家下家顺序分零头。
- 只剩一个未弃牌的人时直接结算；所有人都全下则直接发完公共牌。
- 手牌比较：5~7 张取最佳 5 张，支持 A2345 轮子顺；牌型引擎经过 3 万手随机对拍校验。

## 快捷键

| 操作 | 键 |
| --- | --- |
| 弃牌 / 过牌 / 跟注 / 加注 / 全下 | `F` / `C` / `K` / `R` / `A` |
| 加注面板内选尺度 | `1` ½池 · `2` ¾池 · `3` 1池 · `4` 全下 · `M` 最小 |
| 确认加注 / 收起面板 | `回车` / `Esc` |
| 下一手 | `空格` |

## 文件结构

```
dezhou/
├── index.html        页面结构（牌桌、行动条、设置、规则、战绩）
├── css/style.css     样式（深色赌场风，适配手机竖屏/横屏与桌面）
├── js/               浏览器直接引用的脚本（由根目录源码同步而来）
│   ├── engine.js     牌型评估、洗牌、随机数、胜率模拟
│   ├── game.js       牌局状态机（下注轮、边池、结算、发牌）
│   ├── ai.js         机器人决策（五档水平 × 三种性格）
│   └── app.js        界面逻辑（渲染、动画、机器人调度、设置）
├── engine.js         ↑ 同一份源码的根目录版本（CommonJS，供 Node 跑测试）
├── game.js
├── ai.js
├── sync.sh           把根目录源码同步到 js/
├── verify.js         牌型引擎测试
└── tests/
    ├── game-test.js  牌局流程 / 边池 / 筹码守恒 / 视角隐藏
    └── ai-test.js    水平分层与对局强度
```

`engine.js` / `game.js` / `ai.js` 都是“双环境”写法：在 Node 里 `require` 走 CommonJS，在浏览器里自动挂到 `window`。

### 开发

逻辑源码以根目录为准，改完执行：

```sh
sh sync.sh          # 同步到 js/ 并做语法检查
node verify.js      # 牌型评估（3 万手对拍）
node tests/game-test.js   # 牌局流程、边池、守恒
node tests/ai-test.js     # AI 水平分层
```

然后刷新浏览器即可。
